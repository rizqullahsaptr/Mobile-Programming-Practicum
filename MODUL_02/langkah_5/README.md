# Modul 02 - Langkah 5 - Column

Proyek Flutter mandiri. Buka folder **langkah_5** ini di Android Studio atau VS Code.

```powershell
flutter pub get
flutter run
```

Source code utama: `lib/main.dart`. Konfigurasi, dependensi, dan aset yang diperlukan sudah berada dalam proyek ini.

Untuk memeriksa proyek: `flutter analyze` dan `flutter test`.
Platform yang disiapkan: Android, iOS, dan web. Build iOS memerlukan macOS/Xcode; akses API di web mengikuti kebijakan CORS server.

## Catatan modul

Langkah 2 baru mendefinisikan KotakBiruJempol; tampilannya masih Hello, Flutter! sesuai urutan PDF. Widget tersebut mulai ditampilkan pada Langkah 3. Setiap langkah adalah program lengkap yang berdiri sendiri.
