# Modul 05 - Tugas - Card musik

Proyek Flutter mandiri. Buka folder **tugas** ini di Android Studio atau VS Code.

```powershell
flutter pub get
flutter run
```

Source code utama: `lib/main.dart`. Konfigurasi, dependensi, dan aset yang diperlukan sudah berada dalam proyek ini.

Untuk memeriksa proyek: `flutter analyze` dan `flutter test`.
Platform yang disiapkan: Android, iOS, dan web. Build iOS memerlukan macOS/Xcode; akses API di web mengikuti kebijakan CORS server.

## Catatan modul

Tiga percobaan lengkap: SizedBox, Spacer, dan Card. Tombol map/phone pada contoh Card mengikuti contoh UI PDF dan belum membuka aplikasi lain. Tombol suka pada tugas dapat diaktifkan/nonaktifkan.
