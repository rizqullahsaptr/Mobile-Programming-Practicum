# Modul 04 - Percobaan 2 - Expanded

Proyek Flutter mandiri. Buka folder **percobaan_2** ini di Android Studio atau VS Code.

```powershell
flutter pub get
flutter run
```

Source code utama: `lib/main.dart`. Konfigurasi, dependensi, dan aset yang diperlukan sudah berada dalam proyek ini.

Untuk memeriksa proyek: `flutter analyze` dan `flutter test`.
Platform yang disiapkan: Android, iOS, dan web. Build iOS memerlukan macOS/Xcode; akses API di web mengikuti kebijakan CORS server.

## Catatan modul

Percobaan Flexible menyediakan tiga variasi fit sesuai PDF. Percobaan Expanded menyimpan seluruh variasi ukuran/flex, termasuk contoh kode g yang terpotong oleh pergantian halaman. Tugas merupakan simulasi antarmuka kontrol musik; belum memutar berkas audio.
