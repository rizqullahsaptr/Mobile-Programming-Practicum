# Modul 03 - Langkah kerja 1-9 - Semua variasi alignment

Proyek Flutter mandiri. Buka folder **langkah_kerja** ini di Android Studio atau VS Code.

```powershell
flutter pub get
flutter run
```

Source code utama: `lib/main.dart`. Konfigurasi, dependensi, dan aset yang diperlukan sudah berada dalam proyek ini.

Untuk memeriksa proyek: `flutter analyze` dan `flutter test`.
Platform yang disiapkan: Android, iOS, dan web. Build iOS memerlukan macOS/Xcode; akses API di web mengikuti kebijakan CORS server.

## Catatan modul

Kesembilan langkah digabung dalam satu file. Dropdown memilih langkah dan properti layout; pilihan contoh suhu mengaktifkan perbandingan baseline. Pada Langkah 2 dan 3 definisi widget baru ditambahkan; perubahan body dimulai pada Langkah 4. Tugas cuaca terpisah sesuai gambar Malang, 25°, Minggu/Senin/Selasa.
