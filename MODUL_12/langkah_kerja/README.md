# Proyek langkah kerja Modul 12

Source utama: `lib/main.dart`. Aplikasi mengikuti PDF Modul 12; pemetaan tiap langkah dan penyesuaian kompatibilitas terdapat di [LANGKAH_KERJA.md](../LANGKAH_KERJA.md).

Buka folder ini di Android Studio atau VS Code dan pilih perangkat Android.

```bash
flutter pub get
flutter run
```

Laporan Word dan screenshot hasil aktual terdapat di [folder laporan](../laporan/). Hasil pemeriksaan tercatat di [VERIFIKASI.md](../VERIFIKASI.md).
