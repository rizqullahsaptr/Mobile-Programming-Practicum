## ▶️ Menjalankan Program

1. Buka folder langkah kerja, percobaan, atau tugas yang ingin dijalankan di Android Studio atau VS Code.
2. Jalankan perintah berikut dari folder proyek tersebut:

```bash
flutter pub get
flutter run
```

Contoh: buka `MODUL_07/percobaan_1`, lalu jalankan kedua perintah di atas.

## UTS — Sela: Panduan Tempat Belajar

Proyek UTS berupa aplikasi Flutter untuk membantu mahasiswa memilih tempat belajar berdasarkan suasana, fasilitas, dan kisaran biaya. Aplikasi menyediakan halaman beranda, daftar tempat dengan pencarian dan filter, serta detail tempat. Data tempat, harga, alamat, dan jam operasional merupakan contoh untuk praktikum.

- [Buka folder proyek UTS](UTS/)
- [Baca panduan dan cara menjalankan Sela](UTS/README.md)

Untuk menjalankan Sela, buka folder `UTS` yang berisi `pubspec.yaml`, lalu jalankan `flutter pub get` dan `flutter run`.
